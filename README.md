# x-clone-enhanced

Polished X/Twitter style clone — improved UI, performance, accessibility, persistence, tests and CI.

Quick start:
```bash
npm install
npm run dev
```

Features:
- Componentized React + Vite app
- LocalStorage persistence
- Smooth animations and responsive layout
- Accessibility: keyboard support & aria attributes
- Tests with Vitest + GitHub Actions CI
